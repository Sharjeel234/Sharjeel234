## 01 / About

I'm a **frontend-focused software developer** who builds responsive, intuitive, and maintainable web applications.

My primary focus is **interface engineering, reusable component systems, and user experience**. I work with React.js, Next.js, TypeScript, and modern styling tools to turn product requirements into functional web experiences.

Beyond the frontend, I use **Node.js, Express.js, MongoDB, PostgreSQL, and REST APIs** to develop and integrate full-stack applications.

My experience spans healthcare software, recruitment systems, AI creative interfaces, e-commerce, and business management tools.
